A TV controls preview for Kart64 TV. No game files included.

- Saved controller bindings with Xbox and PS5 labels, axis mapping/inversion and deadzones.
- Live controller input testing and four assignable browser player slots.
- A kart-themed pause menu: Resume, Controls, Sound, Display and confirmed Save & Exit.
- Controller loss pauses the game; reconnecting waits for explicit Resume.
- Actual boot stages and elapsed time, plus a loading error/retry screen.
- Includes the polished Windows progress screen and searchable TV guide.

The pause/resume hooks and gameplay input mapping passed real-game PC browser checks. Android TV emulator checks cover APK update, engine startup, Back and remote menu navigation. **Physical Xbox/PS5 behaviour, multiplayer, Android race visuals and real-TV performance remain unverified.** See [controls, limitations and test evidence](https://github.com/Ticklect/kart64-tv/blob/v1.0.2-preview1/docs/TV-CONTROLS.md).

Choose the Windows EXE to prepare/install your own supported game data, or the ARM32/ARM64 APK matching your Android/Fire OS TV. Use the universal APK if unsure. Updating this APK preserves private game files and adds the shell to the supported existing install; a clean APK install still needs the PC to supply game data. Vega OS is unsupported.

This is a **prerelease**. The stable release and Downloader code 7989374 remain on 1.0.1.
